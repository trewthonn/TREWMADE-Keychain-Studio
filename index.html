How to assign colors in Bambu Studio
  1. Download the 3MF and import it as geometry into Bambu Studio. Keep your own printer and filament settings.
  2. Open the Objects list and expand the keychain. Backing, Name, and Image are separate named parts.
  3. Choose a filament for each part, then slice. If your version imports the assembly as one item, use Split → To parts first.
  4. For STL fallback, unzip and select all files together. Import them as a single object with multiple parts to preserve alignment.

The model uses millimeters and a flat backing. Preview colors are a guide; check filament assignments, fine details, and sliced layers before printing.
